# ฟอนต์ไทย — ต้องเปลี่ยนก่อนปล่อยเกม

`thai_ui.ttf` / `thai_ui_bold.ttf` ตอนนี้คือ **Leelawadee UI ของ Microsoft**
ที่ก๊อปมาจาก C:\Windows\Fonts เพื่อให้เห็นภาษาไทยตอนพัฒนาเท่านั้น

ลิขสิทธิ์ของมัน **ห้ามแจกจ่ายไปกับซอฟต์แวร์** ถ้าปล่อยเกมทั้งอย่างนี้คือละเมิด

## วิธีแก้ก่อนปล่อย
ดาวน์โหลด Noto Sans Thai (ลิขสิทธิ์ SIL Open Font License แจกได้ฟรี)
จาก https://fonts.google.com/noto/specimen/Noto+Sans+Thai
แล้ววางทับเป็นชื่อเดิม `thai_ui.ttf` กับ `thai_ui_bold.ttf`
ไม่ต้องแก้โค้ดหรือซีนใดๆ ทั้งสิ้น

ทางเลือกอื่นที่แจกได้: IBM Plex Sans Thai, Sarabun, Kanit (OFL ทั้งหมด)
