# LUMEN

เกม 2D Vertical Platformer — ไต่หอคอยขึ้นไปจุดไฟที่ดับไปแล้วบนยอด
สร้างด้วย Godot 4.7

> ทำไว้เล่นกันในกลุ่มเพื่อน ไม่ได้ทำเพื่อจำหน่าย

## เกี่ยวกับเกม

โลกนี้ไม่เคยมีดวงอาทิตย์ มีแต่ **ลูเมน** ดวงไฟที่ถูกจุดค้างไว้บนยอดหอคอย
สามร้อยปีมันส่องให้ทั้งเมือง แล้ววันหนึ่งมันก็ดับ
ทุกปีมีคนหนึ่งคนได้ถ่านไฟติดมือขึ้นไป — สี่สิบคนแล้วที่ไม่มีใครกลับลงมา

คุณคือคนที่สี่สิบเอ็ด

## การเล่น

| ปุ่ม | ทำอะไร |
|---|---|
| ← → | เดิน |
| Space (กดค้าง) | ชาร์จแรงกระโดด · ปล่อยเพื่อกระโดด · กดทิศพร้อมปล่อยเพื่อกระโดดเฉียง |
| Esc | หยุดชั่วคราว |

ไม่มีเซฟระหว่างทาง ตกแล้วตกเลย

## หอคอย 5 โซน

| โซน | ชั้น | อุปสรรค |
|---|---|---|
| รากที่จมน้ำ | 1–8 | หินเปียกลื่น ยืนเฉยๆ แล้วไถลออกขอบ |
| หอจดหมายเหตุ | 9–17 | แท่นยุบหลังเหยียบ ไฟสั่นถี่ขึ้นเป็นการนับถอยหลัง |
| เส้นเลือดเตาหลอม | 18–26 | ท่อไอเย็นพ่นเป็นจังหวะ ความสว่างคือนาฬิกา |
| มงกุฎแก้ว | 27–36 | ลมพัดสวิงตลอดโซน |
| ห้องตะเกียง | 37–43 | พื้นหิมะ ยืนแล้วขยับแนวนอนไม่ได้ ต้องกระโดดอย่างเดียว |

**ไวยากรณ์แสง** — ขอบทอง = เหยียบได้ · ขอบฟ้าเย็น = กับดัก
กฎนี้ใช้เหมือนกันทั้ง 5 โซน เรียนครั้งเดียวใช้ได้ตลอดเกม

## โครงสร้างโปรเจกต์

```
Scenes/     Title · Options · Intro · Tower · Ending
Scripts/    ตัวละคร กล้อง ระบบแสง เนื้อเรื่อง ภาษา ค่าตั้ง
Scripts/Tower/  อุปสรรคประจำโซน
Entities/   ฉากย่อยที่ถูก instance ซ้ำ
Resources/  ZoneProfile 5 โซน · Environment · TileSet
Tools/      สคริปต์เจนอาร์ตและเจนเลเวล (ดูด้านล่าง)
```
